# Plan ahead: festivals, big shows, the next month

1. `lsa window --days 35` lists recurring dates in the next five weeks and annual events coming up.
2. For each annual event in `coming_up`: search for this year's dates, prices and on-sale dates. Many annual events shift by a week or two; never assume last year's date.
3. Search the top interests for big shows announced in the period (touring artists they follow, festival lineups, art-week parties). Note on-sale and presale dates.
4. Save candidates and run `lsa digest --days 35 --events-file <file> --title 'Next five weeks'`.
5. Group the final answer by week. Flag anything that sells out (on-sale date, presale code source) so they can decide in time.
6. Buying is theirs: link the official ticket page; never purchase or join presales without an explicit yes.
