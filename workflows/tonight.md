# Tonight

Same as the weekend flow, shorter and faster.

1. `lsa plan --tonight` (5pm today to 4am). Use `--date` if the user's date differs.
2. Check only P1 sources, their top-interest rooms and walk-in fallbacks. Aim for 5–10 minutes of research.
3. Prefer things that don't need a ticket bought in advance, or still have door tickets.
4. `lsa digest --tonight --events-file <file> --title 'Tonight'`.
5. If nothing clears the bar, say so plainly and offer the walk-in fallbacks (they're in the profile) rather than padding the list.
6. Remind them to check the venue's socials before leaving if the night is volatile (DJ sets, pop-ups, weather-dependent).
